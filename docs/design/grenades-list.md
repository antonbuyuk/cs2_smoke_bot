# Grenades List — Design Brief

Страница управления линапами гранат. Есть шапка навигации.

## Элементы

- Заголовок страницы "Lineups"
- Кнопка "+ Add Lineup" — открывает форму добавления
- Ссылка "← Home"

### Форма добавления (скрыта по умолчанию, открывается по кнопке)

- Заголовок "Add new lineup", кнопка закрытия
- Поля: Name (обязательное), Map (select), Side (select), Difficulty (select), Line (необязательное, select), Grenade Type (select)
- Textarea инструкций
- Зона загрузки файлов (drag-and-drop): фото и видео, максимум 10 файлов
- Список загруженных файлов с возможностью изменить порядок (drag handle) и удалить каждый файл; первый файл помечается как обложка
- Сообщение об ошибке / успехе
- Кнопки "Submit" и "Cancel"

### Список линапов

- Фильтр по карте (select)
- Карточки линапов (2 колонки): название, карта, сторона, тип гранаты, сложность, линия, текст инструкции, ссылка "More →"
- Состояния: загрузка, ошибка, пустой список ("No lineups found")
