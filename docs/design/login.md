# Login — Design Brief

Страница аутентификации администратора CS2-бота. Нет шапки и навигации.

## Элементы

- Заголовок "CS2 Bot Admin" и подзаголовок "Войдите через Telegram для доступа к панели управления"
- Кнопка входа через Telegram (виджет Telegram Login)
- Состояние загрузки виджета: текст "Загрузка виджета..."
- Блок ошибки (показывается при неудачном входе): текст "Доступ запрещён. Требуются права администратора."
- Мелкий текст внизу: "Используя эту панель, вы соглашаетесь с условиями использования"
