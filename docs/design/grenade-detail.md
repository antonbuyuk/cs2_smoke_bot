# Grenade Detail — Design Brief

Страница детального просмотра одного линапа. Только чтение, без редактирования. Есть шапка навигации.

## Элементы

- Ссылка "← Back to grenades"
- Название линапа (h1)
- Мета-строка: карта, сторона, линия, сложность
- Текст инструкций
- Сетка медиафайлов: фотографии (`<img>`) и видео (`<video controls>`) с подписями
- Состояния: загрузка (спиннер), ошибка, пустые медиа ("No media available")
