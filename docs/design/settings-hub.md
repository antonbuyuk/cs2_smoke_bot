# Settings Hub — Design Brief

Хаб настроек — навигация по редакторам справочных таблиц. Есть шапка навигации.

## Элементы

- Заголовок "Settings", подзаголовок "Manage reference data"
- Ссылка "← Home"
- 5 карточек-ссылок на справочные таблицы. Каждая карточка содержит:
  - Иконку, название, количество записей, краткое описание, стрелку →
  - Таблицы: Maps (🗺️), Sides (⚔️), Difficulties (📊), Lines (📍), Grenade Types (💣)
- Информационный блок внизу с заголовком "Reference Tables" и пояснением, что эти таблицы используются во всём приложении и удаление связанных записей будет заблокировано
- Состояние загрузки (пока грузятся счётчики)
