# Reference Table — Design Brief

Редактор справочной таблицы (применимо ко всем 5: Maps, Sides, Difficulties, Lines, Grenade Types). Есть шапка навигации. Пример — страница Maps.

## Элементы

- Заголовок страницы (название таблицы, например "Maps")
- Кнопка "+ Add Map" — открывает форму добавления
- Ссылка "← Back" (на /settings)

### Форма добавления (скрыта по умолчанию)

- Заголовок "Add new Map", кнопка закрытия
- Поле "Name (Key)": текстовый input, только строчные буквы/цифры/подчёркивание
- Поле "Display Name": текстовый input, человекочитаемое название
- Сообщение об ошибке
- Кнопки "Add Map" (с состоянием загрузки "Adding...") и "Cancel"

### Таблица записей

- Колонки: ID | Name (Key) | Display Name | Actions
- Кнопка "Удалить" в каждой строке (с состоянием "Удаление..." пока идёт запрос)
- Счётчик внизу: "Total maps: N"
- Сообщение об ошибке удаления (если запись используется в линапах — 409 конфликт)
- Состояния: загрузка, ошибка загрузки, пустая таблица ("Maps not found")
